# Database setup
This project uses both MySql and Redis.

This file is originally run by using Ubuntu 20 with docker-snap which is bit different from docker desktop
More info https://github.com/canonical/docker-snap/blob/main/README.md
To start and stop database 
  - docker compose up -d
  - docker compose down
